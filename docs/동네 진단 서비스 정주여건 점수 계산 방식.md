# 동네 진단 서비스 — 정주여건 점수 계산 방식

Nov 3, 2026 · @이승엽

## 배경과 원칙

점수는 시설 **개수**가 아니라 **시설의 중요도 × 거리 × 포화**로 계산한다. 반경 안 병원이 많아도 피부과뿐이면 응급 상황에는 도움이 안 되고, 상점이 많아도 생필품을 팔지 않으면 정주여건과 무관하기 때문이다.

계산 방식은 다음 네 원칙을 따른다.

1. **유형 가중치**: 같은 카테고리 안에서도 시설 유형별로 중요도를 다르게 준다 (종합병원 > 내과 의원 > 피부과).
2. **거리 감쇠**: 같은 반경 안이라도 가까운 시설일수록 높게 친다.
3. **포화**: 일정 개수를 넘으면 점수가 거의 오르지 않게 해서, 번화가가 점수를 독식하지 않게 한다.
4. **상대 비교**: 최종 점수를 사상구 전체 분포와 비교한 백분위로도 보여줘서, 팀이 임의로 정한 숫자보다 데이터에 근거한 지표가 되게 한다.

## 계산 대상 데이터

기본 계산은 정주여건의 필수 요소 5개 카테고리로 하고, 사용자가 옵션을 켜면 3개 카테고리가 추가된다. 모든 시설은 DB 테이블 하나에 위도·경도 좌표로 저장되어 있다.

| 구분 | 카테고리 | 유형 구분에 쓸 데이터 항목 |
| --- | --- | --- |
| 기본 | CCTV (안전) | 설치 목적 (방범용 등) |
| 기본 | 병원 (의료) | 종별코드명, 진료과목 |
| 기본 | 상점 (생필품) | 업종 대·중·소분류 |
| 기본 | 버스정류소 | 경유 노선 수 |
| 기본 | 지하철역 | (구분 없음) |
| 옵션 | 어린이집 | (구분 없음) |
| 옵션 | 노인복지시설 | (구분 없음) |
| 옵션 | 어린이보호구역 사고 장소 | 감점 요소 |

데이터 정규화 단계에서 테이블에 `category`(카테고리), `sub_type`(세부유형), `weight`(유형 가중치) 컬럼을 미리 넣어두면 점수 계산 때 별도 판단 없이 바로 쓸 수 있다.

## 단계별 계산 공식

선택 지점에서 각 시설까지의 거리를 구하고, 시설 하나의 기여값 → 카테고리 점수 → 총점 순서로 계산한다.

### 1단계. 거리 (하버사인 공식)

위도·경도로 실제 거리(m)를 구하는 표준 공식이다. 각도는 모두 라디안으로 바꿔서 넣는다.

```latex
a = \sin^2\left(\frac{\Delta\varphi}{2}\right) + \cos\varphi_1 \cos\varphi_2 \sin^2\left(\frac{\Delta\lambda}{2}\right), \qquad d = 2R \arcsin\sqrt{a}, \quad R = 6{,}371{,}000\,\text{m}
```

φ는 위도, λ는 경도, Δ는 두 지점의 차이다.

### 2단계. 시설 하나의 기여값

```latex
v_i = w_i \times f(d_i), \qquad f(d) = \max\left(0,\ 1 - \frac{d}{r_c}\right)
```

- wᵢ: 시설 유형 가중치 (예: 종합병원 1.0, 피부과 0.1)
- f(d): 거리 감쇠. 바로 앞이면 1, 반경 끝이면 0
- r\_c: 카테고리별 반경

### 3단계. 카테고리 점수 (포화 함수)

```latex
X_c = \sum_{i \in c} v_i, \qquad S_c = 1 - e^{-X_c / k_c}, \qquad k_c = \frac{n_c}{6}
```

n\_c는 "이만큼 있으면 충분하다"는 목표 개수다. k\_c = n\_c / 6으로 잡으면 가중치 1인 시설 n\_c개가 반경 중간쯤에 있을 때 점수가 약 0.95가 된다 (ln 20 ≈ 3). 그 이상 늘어도 점수는 거의 오르지 않는다.

### 4단계. 종합병원은 최근접 거리로

종합병원은 반경 몇백 m 안에 없는 게 보통이라, 개수 대신 가장 가까운 곳까지의 거리 d\_min으로 점수를 매긴다.

```latex
S_{\text{종합}} = \begin{cases} 1 & d_{\min} \le 1000 \\ \dfrac{5000 - d_{\min}}{4000} & 1000 < d_{\min} < 5000 \\ 0 & d_{\min} \ge 5000 \end{cases} \qquad S_{\text{의료}} = 0.5\,S_{\text{의원급}} + 0.5\,S_{\text{종합}}
```

S\_의원급은 동네 의원들을 3단계 방식으로 계산한 점수다.

### 5단계. 총점

```latex
T = 100 \times \left(\sum_c W_c \, S_c\right) \times (1 - 0.2\,P)
```

- W\_c: 카테고리 가중치, 합이 1
- 옵션을 켜면 해당 카테고리를 추가하고 W\_c' = W\_c / ΣW로 다시 나눠 합을 1로 맞춘다. 그래야 옵션을 켜도 만점이 100으로 유지된다.
- P: 반경 안 어린이보호구역 사고 장소를 3단계 방식으로 계산한 0\~1 값. 최대 20% 감점한다. 옵션을 안 켜면 P = 0.

### 6단계. 백분위 (상대 점수)

사상구 전체를 일정 간격 격자로 나눠 모든 격자점의 총점을 미리 계산해 두고, 사용자가 고른 지점과 비교한다.

```latex
\text{백분위} = \frac{\text{총점이 } T \text{ 이하인 격자점 수}}{\text{전체 격자점 수}} \times 100
```

화면에는 "사상구 내 상위 15%"처럼 표시한다.

## 파라미터 초안

아래 숫자는 출발점이고, 팀 논의와 실제 데이터로 돌려본 결과를 보고 조정한다.

| 카테고리 | 카테고리 가중치 W\_c | 반경 r\_c | 목표 개수 n\_c | 유형 가중치 wᵢ |
| --- | --- | --- | --- | --- |
| 안전 (CCTV) | 0.20 | 300m | 4 | 방범용 1.0 / 그 외 0.3 |
| 의료 (의원급) | 0.25 | 500m | 2 | 내과·가정의학과·소아과 0.6 / 피부과·성형외과 0.1 |
| 의료 (종합병원) | (위와 합산) | 최근접 1\~5km | – | 4단계 공식 |
| 생필품 상점 | 0.20 | 400m | 3 | 마트·편의점·약국 1.0 / 그 외 제외 |
| 버스정류소 | 0.15 | 400m | 2 | min(1, 경유 노선 수 ÷ 5) |
| 지하철역 | 0.20 | 800m | 1 | 1.0 |
| 어린이집 (옵션) | 0.15 | 500m | 2 | 1.0 |
| 노인복지시설 (옵션) | 0.15 | 500m | 2 | 1.0 |
| 사고 장소 (옵션) | 감점 최대 20% | 300m | 3 | 1.0 |

가중치를 정할 근거는 두 가지를 추천한다.

- **AHP(계층분석법)**: 항목을 두 개씩 짝지어 "어느 쪽이 얼마나 더 중요한가"를 비교해 가중치를 뽑는 방법. 팀원과 주변 자취생 몇 명에게 설문해서 계산하면 발표 때 근거로 제시할 수 있다.
- **공공 기준**: 국토교통부 도시재생 관련 기초생활인프라 최저기준에 시설별 적정 도보 거리가 있어 반경 설정 근거로 쓸 수 있다 (원문 확인 필요).

## 계산 예시

가상의 A 지점은 위 파라미터로 **약 85.1점**이 나온다 (옵션 없음, 실제 계산으로 확인한 값).

| 카테고리 | 반경 안 시설 | S\_c |
| --- | --- | --- |
| CCTV | 방범용 50m·120m·200m, 교통용 100m, 기타 280m | 0.949 |
| 의원급 | 내과 200m, 피부과 100m | 0.733 |
| 종합병원 | 가장 가까운 곳 1.8km | 0.800 |
| 의료 합산 | 0.5 × 0.733 + 0.5 × 0.800 | 0.766 |
| 생필품 | 편의점 100m·250m·380m | 0.905 |
| 버스 | 150m(노선 8개), 300m(노선 2개) | 0.886 |
| 지하철 | 600m | 0.777 |

```latex
T = 100 \times (0.2 \times 0.949 + 0.25 \times 0.766 + 0.2 \times 0.905 + 0.15 \times 0.886 + 0.2 \times 0.777) \approx 85.1
```

### 개수보다 중요도가 반영되는지 확인

100m 거리에 피부과 5곳이 있는 지점보다 내과 1곳이 있는 지점의 의원급 점수가 더 높다.

| 지점 | 계산 | S\_의원급 |
| --- | --- | --- |
| 피부과 5곳 | X = 5 × 0.1 × 0.8 = 0.40 | 0.699 |
| 내과 1곳 | X = 0.6 × 0.8 = 0.48 | 0.763 |

## 구현 참고사항과 다음 할 일

- 결과 화면에는 총점만 띄우지 말고 "반경 400m 내 편의점 4곳, 가장 가까운 종합병원 1.2km"처럼 항목별 근거를 같이 보여준다.
- 사고 장소는 더하지 말고 반드시 감점으로 처리한다. 더하면 사고가 많은 곳의 점수가 오른다.
- 반경 조회는 위도·경도 범위(사각형)로 DB에서 후보를 먼저 걸러낸 뒤, 하버사인으로 정확한 거리를 계산하면 빠르다.

* [ ] 카테고리 가중치 W\_c 확정 (AHP 설문 또는 팀 논의)
* [ ] 정규화 단계에 category, sub\_type, weight 컬럼 추가
* [ ] 병원 진료과목·상가 업종 코드별 유형 가중치 표 작성
* [ ] 사상구에서 잘 아는 지점 3\~5곳(번화가, 주거지, 외곽)에 돌려보고 점수 순서가 상식과 맞는지 확인
* [ ] 사상구 격자점 점수를 미리 계산해 백분위 기준 만들기
